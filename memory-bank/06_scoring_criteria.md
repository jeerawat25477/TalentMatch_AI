## ต้นเหตุร่วม

AI เป็นคนตัดสินว่าอะไร "บังคับ" อะไร "โบนัส" ตอนสร้างตำแหน่ง และจัดกลุ่มผิดได้ทั้งสองทิศ:
- **ของจำเป็นไปอยู่ในโบนัส** → กรณีมีแค่ preferred: ฝั่งนั้นคิดเต็ม 100 คนไม่มีโบนัสได้ 0
  แล้วถูกปฏิเสธอัตโนมัติ (ยังไม่เกิดในข้อมูลจริง)
- **ของไม่จำเป็นไปอยู่ในบังคับ** → เกิดแล้วกับ AI Engineer ทั้งสองฉบับ คะแนนทุกคนต่ำจนไม่มีความหมาย

สองจุดในโค้ดที่ทำให้เป็นแบบนี้:
- prompt ใน `backend/app/agents/nodes/jd_analyzer.py` ไม่มีกติกาเรื่อง "or" / "such as" /
  หน้าที่งาน
- `models.py::JobRequirement` เป็นรายการแบนที่ทุกข้อต้องมีครบ (AND) **เก็บความหมาย
  "ข้อใดข้อหนึ่ง" ไม่ได้เลย** แก้ prompt อย่างเดียวจึงไม่หาย

**ทำงานอย่างไร (1 call ต่อตำแหน่งเท่าเดิม):**
- LLM คืน `JDExtraction` = ทุกคำพร้อมป้าย `source_line`, `kind` (technology/method/knowledge_field/
  duty/category/role/personal/education), `necessity` (must/one_of/example/plus), `section`
  (duties/qualifications/unsectioned), `group`

- ตาข่ายในโค้ดที่ไม่พึ่งป้าย: ท่อนประโยคที่มี or/หรือ + ทักษะ ≥ 2 ตัว → อยากได้ · ประกาศไม่มีหัวข้อ
  ถ้าบรรทัดมีคำที่ติดเป็นหน้าที่งาน ทั้งบรรทัดนับเป็นหน้าที่ · ตัดคำต่อท้าย ("Python Programming"
  → "Python") แต่ไม่ตัดถ้าเหลือคำกว้าง ("Web Development") · หาบรรทัดจริงในประกาศแทนการเชื่อ
  source_line ที่ LLM ยกมา

## ปุ่ม "ให้ AI อ่านประกาศใหม่" (2026-09-20)

- อยู่ในหน้าต่างแก้เกณฑ์ · `POST /api/v1/jobs/{id}/criteria/reanalyze` ใช้ 1 call ไม่ retry
  (5 ครั้ง/นาที, 429 ถ้าโควตาเต็ม, 502 ถ้า AI ล้ม)

- ปุ่ม "คืนค่าตามที่ AI ดึง" ถูกลบจากหน้าเว็บ (ซ้ำกับปุ่มนี้ และบันทึกโดยไม่แสดงผลกระทบ)
  endpoint `/criteria/reset` ฝั่ง backend ยังอยู่ แต่หน้าเว็บไม่เรียกแล้ว
- ตอนนี้บันทึกได้ทางเดียว: ปุ่ม "บันทึกและคำนวณใหม่" หลังเห็นผลกระทบ

## ทางแก้ข้อ 3: กลุ่ม "ข้อใดข้อหนึ่ง" (2026-09-20)

- **เก็บเป็นข้อความในรายการเดิม คั่นด้วย `|`**: `"PyTorch | TensorFlow | Hugging Face"` = 1 ข้อ
  มีตัวใดตัวหนึ่งก็ผ่าน · ไม่แก้ schema / JobRequirement / API · แสดงบนเว็บเป็น "…หรือ…"
- เทียบ: `skills.matching_owned` ลองทีละตัวเลือก (แยก `|` **ก่อน** canonical เพราะ canonical ลบเครื่องหมาย)
  สูตรไม่แตะ — กลุ่มเป็น 1 รายการในตัวหารอยู่แล้ว
- จัดกลุ่มอัตโนมัติ: `jd_analyzer.to_requirement` รวมจากป้าย `group` (บรรทัดเดียวกัน) + ท่อน or/หรือ
